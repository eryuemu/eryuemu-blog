## 💡 简明省流版（30 秒速览）

> **一句话总括**：搭建和维护一个独立博客，最耗费心神的往往不是写代码，而是 DNS 解析、重定向、搜索引擎爬虫机制以及各种“黑盒报错”。本文结合本站从零上线的 12 篇硬核复盘笔记，将域名选购、DNS 排错、国内访问优化、技术栈选型、工程自动化、SEO 规范与心态建设，系统性总结为 **19 条直击本质的建站必备意识与实战认知金句**。以后无论是新建站点还是日常排错，对照此清单即可避开 99% 的弯路。

## 🚀 独立建站必备意识清单（19 条实战法则）

---

### 一、 域名与 DNS 意识（门牌与身份）

#### 1. 保持站长控制台、主域名、Canonical 规范链接三位一体，统一一个主域名。
* **原理解读**：切忌根域名（`eryuemu.com`）和 `www.eryuemu.com` 两头摇摆。必须定死一个作为唯一主站，另一个只做 308 永久重定向。全站内部链接、Sitemap 网站地图、代码里的 `<link rel="canonical">` 规范标签以及 Google Search Console / Bing 站长平台的资源名，必须全部对齐这同一个门牌号，彻底避免搜索引擎产生“重定向报警”或索引权重分散。

#### 2. 买域名首年看促销，长久看续费与转移。
* **原理解读**：域名注册商首年通常有极低优惠码（如 Spaceship 的 COMPROS 优惠码只需 $2.90），但第二年续费会回归正常价。根据 ICANN 规则，新注册域名在 60 天锁定期过后，可随时转入 Cloudflare 等提供零利润批发价（At-cost Pricing）的平台长期持有。另外绝对不要等域名过期再去捡漏，过期后的保护期会被抢注机器人秒杀。

#### 3. 域名后缀决定第一印象，能选 `.com` 就别碰杂牌后缀。
* **原理解读**：个人技术博客首选 `.com`（国际硬通货）、`.dev`（强制 HTTPS 极客专供）、`.me`（个人品牌标配）。绝对避开 `.top`、`.win`、`.trade` 等由于历史低价倾销而被黑产滥用、极易被企业防火墙、校园网和杀毒软件直接拦截的垃圾站高危后缀。

#### 4. 频繁改 DNS 先把 TTL 调成 1 分钟，排错不抓狂。
* **原理解读**：DNS 记录生效慢往往是因为三层缓存叠加：本地操作系统缓存、家用路由器缓存、省市运营商递归 DNS 缓存。在频繁切换 IP 或调试 CNAME 记录时，先把 TTL 临时设为 60 秒（1 分钟），等测试完全通畅后再改回 30 分钟或更长，避免因缓存未过期导致排错抓狂。

#### 5. 国内打不开别轻易甩锅给服务器 IP，先查域名是不是被 DNS 污染了。
* **原理解读**：防火墙 GFW 查的是域名这张“身份证”，不是服务器“房子 IP”。Vercel 的默认后缀 `*.vercel.app` 在国内遭遇了域名级 DNS 污染（查地址环节直接拿不到真 IP），但其实 Vercel 的底层经典 IP（`76.76.21.21` / `216.198.79.1`）国内均可直连。只要绑定上自己的干净独立域名，就能绕开污染实现全国秒开。

### 二、 架构与选型意识（适合大于一切）

#### 6. 先跑通自动部署流水线，内容充实了再买域名。
* **原理解读**：自动化流水线比域名更值钱。建站初期先用 Vercel 或 GitHub 提供的免费二级域名，打通 `本地 Markdown 写作 -> git push -> CI/CD 自动编译上线` 的完整闭环并调好样式，等内容充实后再买域名绑定，避免收费域名在建站初期白白空转消耗年费。

#### 7. 文档 Wiki 追求局部切页选 VitePress，个人博客追求极致首屏与 SEO 选 Astro。
* **原理解读**：知识库 Wiki 需要高频树状翻阅和即时响应，SPA（单页应用）架构的 VitePress 体验极佳；而个人独立博客追求的是首屏瞬开、零 JavaScript 负担与完美的搜索引擎多页爬取，Astro 的默认零 JS 静态输出和 Islands（孤岛架构）更具优势。

#### 8. 根据读者群体决定评论系统，不给非技术读者设门槛。
* **原理解读**：纯程序员的技术文档站用 Giscus（基于 GitHub Discussions）零后端成本、完全免费；但如果个人博客包含二次元、随笔、生活杂谈与技术大杂烩，必须使用 Waline 等支持免登录匿名评论的系统，非程序员读者没有 GitHub 账号也能顺畅留言交流。

#### 9. 能做最短直连链路，就坚决不盲目“套娃”。
* **原理解读**：架构设计遵循奥卡姆剃刀原则。当前托管在 Vercel 上的博客，直接使用 Spaceship DNS 解析至 Vercel IP 是最短、故障率最低的路径。若没有特殊的全球 WAF 防火墙、边缘 Worker 脚本或企业邮箱转发需求，不要盲目在前面套一层 Cloudflare CDN，否则只会徒增 SSL 520/525 握手失败与双重缓存的调试复杂度。

### 三、 工作流与工程意识（写作归写作，发布归发布）

#### 10. 本地写作环境与线上代码仓库物理隔离，坚决不手动复制粘贴。
* **原理解读**：Obsidian 专注在本地负责纯粹的思考、双链笔记沉淀与草稿写作；WSL2 与项目构建脚本在后台负责 WikiLink 转换与 Markdown 结构化清洗；Git 一键推送触发云端自动构建。写作与工程互不干扰，永远不走低效易错的手动复制粘贴。

#### 11. 站点路由变动后，第一时间排查内链转换脚本。
* **原理解读**：当站点从二级目录（如 GitHub Pages 的 `/eryuemu-blog/`）迁移到独立域名的根路径时，除了修改主配置文件，必须第一时间全局排查文章内链与图片转换脚本（如 `migrate.cjs`），确保生成的站内链接前缀同步修正，防止整站内链全部 404。

#### 12. 第三方授权遵循最小权限原则，敏感密钥永不上库。
* **原理解读**：第三方平台（如 Vercel）授权 GitHub 仓库时，遵循最小权限原则，只勾选当前博客单个 Repo，不暴露整个个人账号；Supabase 数据库连接密码、Waline 服务端 Token 等敏感密钥一律存放在 Vercel 环境变量中，代码库中只保留占位符，严防泄露。

### 四、 SEO 与爬虫心理学意识（降维打击与反焦虑）

#### 13. 单页面永远只保留唯一一个核心 `<h1>`，开屏动画等遮罩层一律用 `<div>`。
* **原理解读**：HTML5 与现代搜索引擎规范要求单页面只能有 1 个核心 `<h1>` 作为主题最高层级。开屏动画（Splash Screen）或 Logo 区域即使视觉字体很大，也必须降级为 `<div>` 或 `<span>`，避免爬虫分不清文章正文的核心标题。

#### 14. 页面标题要中英双语、丰满清晰，拒绝只有十几个英文字符的裸跑。
* **原理解读**：首页 `<title>` 长度建议保持在 50~60 字符左右，包含“作者中文名 + 英文 ID + 博客品牌名 + 核心技术领域”。纯英文过短的标题（如 `eryuemu's blog` 仅 14 字符）会导致中文分词索引命中率极低，难以在中文搜索结果中排到前列。

#### 15. Meta 描述要详尽且说人话，否则 Google 会直接弃用并自行抓取正文。
* **原理解读**：页面 `<meta name="description">` 保持在 80~100 字（150 字符）的标准区间，真实生动地概括站点定位。若 Meta 过于简短（如 30 多字），Google 爬虫会判定为信息不足而主动丢弃 Meta，转去正文胡乱抓取段落当摘要；写满规范 Meta 还能直接利好 Google AI Overview（AI 概览）精准提炼博主画像。

#### 16. 全站页面启用 Clean URLs 保持干净后缀，不留 `.html` 替身产生备用网页报警。
* **原理解读**：保持全站路由后缀的绝对纯净与统一。文档站如果开启了不带 `.html` 的干净路径，就必须在配置中将 `cleanUrls` 设为 true，让导航侧边栏、Sitemap 地图与 Canonical 规范链接 100% 去掉 `.html`，防止爬虫把不带后缀的页面判定为“备用网页”而拒绝收录。

#### 17. 站长平台的静态建议是“代码体检表”，绝不是“死刑判决书”。
* **原理解读**：搜索引擎的抓取管道分为两层：第一层快速爬虫只负责抓词入库（只求快，不跑复杂体检）；第二层 SEO Recommendations 建议报告是后台低优先级的离线批处理任务（1~2 周才批量扫一次库）。在站长平台看到红黄色感叹号只是静态代码规范提醒，并非网站被降权或 K 站。

#### 18. 域名重定向与全站批量改动后，必然会有 1~3 周的搜索真空与权重交接期。
* **原理解读**：主域名反转（从 `www` 切换到根域名）并配置 308 永久重定向后，搜索引擎下架旧域名索引、重新爬取新根域名并完成历史权重合并需要 1~3 周。在此期间，搜索直接搜名字可能会暂时后移，用 `site:eryuemu.com` 即可查到底层真实收录，切忌在过渡期频繁改动配置。

#### 19. 地基打牢后彻底断舍离，博客是写给自己和朋友看的，不做搜索引擎的奴隶。
* **原理解读**：SEO 是底层架构做规范之后的自然副产物。把 DNS、单 `<h1>`、中英双语 Title、Meta 描述和 Sitemap 等技术地基一次性打牢后，就可以把站长后台彻底关掉。个人独立博客的核心价值在于真实的思考、生活与技术沉淀，持续产出高质量原创内容，才是独立博客长青的唯一真理。
